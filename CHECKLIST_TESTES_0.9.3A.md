# Checklist 0.9.3A

1. Criar contrato com veículo Disponível: deve virar Reservado.
2. Tentar criar outro contrato para o mesmo veículo: deve bloquear.
3. Enviar por WhatsApp: contrato deve virar Enviado.
4. Abrir link público: contrato deve virar Visualizado.
5. Alterar para Assinado: veículo deve virar Alugado e vincular motorista/contrato.
6. Encerrar escolhendo Disponível: veículo deve ser liberado.
7. Repetir e encerrar escolhendo Manutenção.
8. Cancelar contrato reservado: veículo deve voltar a Disponível.
9. Conferir dashboard e histórico do veículo.
10. Confirmar que não é possível excluir veículo reservado/alugado.
