# Sprint 0.9.3A — Motor de Estados

- Veículo passa a Reservado quando o contrato é gerado.
- Veículo passa a Alugado somente quando o contrato é Assinado/Ativo.
- Cancelamento libera a reserva.
- Encerramento permite enviar o veículo para Disponível ou Manutenção.
- Bloqueio de contrato duplicado para o mesmo veículo.
- Histórico operacional do veículo.
- Dashboard com Disponíveis, Reservados, Alugados e Manutenção.
- Exclusão bloqueada para veículos com contrato vigente.
- WhatsApp altera contrato para Enviado e abertura pública para Visualizado.
